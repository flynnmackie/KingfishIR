Every new terminal you open starts deactivated — you'll need to run the .venv\Scripts\Activate.ps1 line again each session to get back into it. VS Code, helpfully, often does this for you once it's noticed the .venv: with the Python extension installed it detects the environment and auto-activates new terminals, and you can also click the Python version in the bottom-right status bar to select .venv as the interpreter, which makes the run button use it too. And second: .venv is a folder you never edit and never submit — it's regenerable from requirements.txt, which is the whole point.

The golden rule for running this project: always run it from inside the remote_triage_tool folder, and your imports start with core., transports., or gui. So it's from core.discovery import ping_ttl — not the longer remote_triage_tool.core...
